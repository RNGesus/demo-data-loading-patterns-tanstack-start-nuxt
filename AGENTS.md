# TanStack Start / Nuxt playground

Monorepo playground for comparing TanStack Start, Nuxt, and Datastar/Hono data-loading patterns.

## Quick Reference

- Use `vp` for scripts, linting, formatting, testing, and builds.
- Use `vp check` for format, lint, and type checks.
- Use `vp test` when behavior changes or tests are relevant.
- Do not call `pnpm`, `npm`, or `yarn` directly.
- Root scripts: `vp run dev`, `vp run tanstack-start#dev`, `vp run nuxt#dev`, `vp run datastar-hono#dev`.
- Root checks: `vp run lint`, `vp run lint:fix`, `vp run typecheck`.
